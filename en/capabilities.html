Capabilities

Three steps that follow each other: design, build, check. Every capability points to a real project.

01

Design

Understand users, organise content and design screens that are easy to use, starting on mobile.

  • ResearchPersonas, use cases, user journeys
  • StructureSitemaps, wireframes, user flows
  • InterfaceFigma mockups and prototypes, responsive design
  • IdentityLogo, palette, typography, print materials

Example: Afghan Community, from research to brand guidelines.

02

Build

Build cleanly, in the tool that suits the client, with content they can manage on their own.

  • WordPressThemes, child themes, ACF, Elementor, forms
  • E-commerceWooCommerce, Wix Stores, catalogues, delivery rules
  • Front-endHTML, CSS, JavaScript and PHP basics
  • MultilingualFR/EN websites, 7-language catalogue

Examples: Pamir-Lux and DressYourBody.

03

Check

Test before publishing: a website must stay readable, fast and accessible for everyone.

  • AccessibilityWAVE, contrast, keyboard navigation
  • PerformanceLighthouse, image weight
  • SEOMetadata, heading structure, content
  • QualityHTML validation, mobile and desktop testing

Example: Lighthouse accessibility 100 on Afghan Community.

How I work

My method, in four steps.

  1. UnderstandClarify the need, the users, the constraints and the expected result.
  2. StructureOrganise content, journeys and screens before building.
  3. Design and buildPrototype, get approval, then build cleanly.
  4. Test and documentCheck quality and deliver a result others can understand.
