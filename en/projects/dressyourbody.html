DressYourBody

Improving a live sewing-pattern store, page by page, without interrupting sales.

  • ContextProfessional internship, 10 weeks
  • PeriodFebruary to April 2026
  • My roleUI/UX, integration, QA
  • ToolsFigma, WordPress, WooCommerce, Elementor, ACF

In 30 seconds · Real project

  1. The need

    Improve a live store without interrupting sales.

  2. What I did

    Figma mockups, staging build, mobile menu, 404, translations, gift cards.

  3. The result

    A 10-week internship, changes approved by the founder, then a redesign demo.

Key numbers

  • 10weeks of internship
  • WooCommercelive store
  • FR+ENTranslatePress
  • 201pages in the redesign demo

The context

DressYourBody is an existing online store. Every change had to improve the experience without breaking the journeys customers already used.

The challenge

Make pages easier to read on mobile and desktop, clarify the purchase journey and fix several technical issues in an existing WordPress and WooCommerce setup.

My role

  • Review of the home page, shop, product pages, cart, checkout and gift cards.
  • Figma mockups and comparisons shared with the founder before every change.
  • Implementation on a staging site: child theme, CSS and PHP, Elementor, ACF.
  • Fixes to the mobile menu, the 404 page, translations and responsive display.
